# Example with 明英科技 (MINGYINGKEJI) standalone

> Standalone runs the core: tables, collaboration, API and automation.
> For the AI features (chat, App Builder, sandboxes) use the
> [full-featured self-host deployment](https://github.com/webb-chen/table) --
> and if you are already running standalone, your data stays in place when
> [upgrading](https://github.com/webb-chen/table).

Look into the `.env` file and update the vaiables before executing `docker compose up -d`.

## The Project

- Accessible via `http://127.0.0.1:7333`
- Uses postgres db for storage
- Telemetry is disabled
